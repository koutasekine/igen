# アイディア生成(igen)

https://igen.sapp.jp

テーマに対してアイディアを出し(発散)、条件を書き足して 1 つの案にまとめる(収束)までを、1 つのテキストで行う単一 HTML のツールです。[S Apps](https://sapp.jp) のアプリの 1 つです。

- 単一 HTML(index.html)だけで動きます。外部ライブラリを使わず、データをどこにも送信しません。ネットワークなしで動きます。
- テキストが正本です。図や表から書き足した内容も、すべて左のテキストに書き込まれます。
- 保存するファイルは `.igen`(UTF-8 のテキスト)です。

## できること

| 区分 | ビュー | 内容 |
|---|---|---|
| 発散 | アイディア一覧(共通入力) | 入力欄に書いて Enter で 1 件ずつ足す |
| 発散 | マンダラート | 3×3 の盤面の空きのマスに書く。マスのアイディアを中心にした盤面も開ける |
| 発散 | 蜂の巣ノート | 六角形の枠を、選んだ枠の隣へ隣へと広げて書く |
| 発散 | マトリックス法 | 縦の項目 × 横の項目の表の、組み合わせのマスに書く |
| 発散 | シックスハット・オズボーンのチェックリスト・SCAMPER・TRIZ の 40 原理 | 対象(テーマかアイディア)に観点を当てて書く |
| 発散 | 欠点列挙法・希望点列挙法・特性列挙法 | 欠点・希望点・特性を挙げ、項目ごとに改善案を書く |
| 収束 | KJ 法 | アイディアをグループにまとめ、上位グループ・説明・関係(関連・因果・対立)と全体のまとめを書く |
| 収束 | セブンクロス | 分類ごとに、アイディアを重要度 1〜7 に置く |
| 収束 | 5W1H | 案ごとに who・what・why・when・where・how を表で書く |
| 収束 | マインドマップ | 元のアイディアをたどった木を見ながら、枝を伸ばして書く |
| 収束 | ストーリーボード | 案の使われ方を、場面の文の並びで書く |
| 収束 | ポジショニング | 2 つの軸の図の上に、アイディアを置く |
| 収束 | 既存調査 | 似た製品・サービス・論文と、自分の案との違いを表に書く |
| 収束 | 候補比較・評価 | 必須の条件(○・×)と評価の観点(1〜5、重み付き)で案を比べる |
| 収束 | 判断・消去法 | 案ごとに採用・代替・見送りと理由を書く。採用は 1 つだけ |

手法を通す順序は自由で、すべての手法を使う必要はありません。

図・表は題の右のボタンで、SVG・PNG・PDF に保存できます。表はタブ区切りの文字としてコピーもできます。

## 書き方の例

```
theme: 学内の落とし物を減らす
author: 青木

- 落とし物を写真で登録する
  by: 青木
  from: mandala
  group: 探す手間を減らす
  who: 落とし物をした学生
  decision: adopt
  reason: 窓口に行かずに探せる

- 利用者の投稿で共有する
  by: 井上
  from: scamper 代用する
  from: 落とし物を写真で登録する
```

書き方の全体は、アプリの「書き方」で見られます。

## 複数人で使う

同時に編集する機能はありません。1 人の画面を共有して皆で埋めるか、各自が同じテーマでアイディアを出し、テキストをコピーして 1 人のテキストの最後に貼り付けます。ファイル全体を貼ってかまいません。テーマが違えば警告が出ます。同じ名前のアイディアは、まとめずに両方残ります。

## 生成 AI と使う

[docs/prompt_for_ai.md](docs/prompt_for_ai.md) を生成 AI に渡すと、この記法でテキストを書いてもらえます。アプリの診断の欄の「修正依頼をコピー」で、エラーや警告を直す依頼の文も作れます。詰まったときは、編集パネルの「AI に相談する文をコピー」で、テーマ・手法・いまの状態を入れた相談の文を作り、生成 AI を壁打ちの相手にできます。

## 開発

- `dev/` に部品があり、`python3 dev/build.py` で index.html を作ります。
- `node dev/test.js` で計算部の試験をします。
- `python3 dev/ui_check.py` で画面の確認をします(Playwright と Chrome が必要です)。
- 仕様は [docs/spec.md](docs/spec.md) にあります。
